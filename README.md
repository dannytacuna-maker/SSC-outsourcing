# CURSOR FILES

Everything for the agent / setup / docs you don’t need day-to-day lives here.

## Contents
- `AGENTS.md`, `CLAUDE.md` — agent guidance
- `project-README.md` — old root project README
- `client-README.md` — client folder notes
- `env.example` — env var template (was `.env.example`)

- `FOTOS-SSC/`, `VIDEOS/`, `client/`, `ONTRACK/`, PDFs/zips — client media
- Config needed to run/deploy: `package.json`, `next.config.ts`, `tsconfig.json`, `.env.local`, etc.
- `.cursor/rules/` — must stay there for Cursor to load rules
