# Countme site

Sister-brand marketing site for Countme (SSC group).

## Stack

- Next.js App Router + TypeScript + Tailwind CSS v4
- Locales: `/es` (default), `/en`

## Develop

```bash
cd COUNTME/web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — redirects to `/es`.

## Deploy

From `COUNTME/web`:

```bash
npx vercel --prod --yes
```
